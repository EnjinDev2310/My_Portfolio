# Portfolio — EnjinDev2310

Portfolio personal con CV, proyectos, experiencia, y contacto. Construido con Angular, Tailwind CSS 4 y Angular Material.

## Stack

- **Angular 21** — framework
- **Tailwind CSS 4** — estilos utilitarios
- **Angular Material** — iconos SVG
- **Vitest** — tests unitarios
- **Playwright** — tests E2E

## Development

```bash
ng serve        # servidor local → http://localhost:4200
ng test         # tests unitarios (Vitest)
ng e2e          # tests E2E (Playwright)
ng build        # build producción → dist/
```

## Secciones

| Ruta | Sección |
|------|---------|
| `/` | Home |
| `/proyects` | Proyectos |
| `/experience` | Experiencia |
| `/contact` | Contacto |
| `/cv` | CV descargable |

## Features

- Modo oscuro con animaciones sutiles
- CV imprimible en una página con datos reales
- Iconos sociales interactivos (Discord, Instagram, GitHub, LinkedIn, Reddit, Telegram)
- Portfolio con proyectos reales
- Tests unitarios + E2E
